# QuizNest frontend

Next.js (App Router, TypeScript, Tailwind v4) frontend for the Online Quiz Application. See the [root README](../README.md) for the full project overview, local dev setup, and deployment instructions.

## Quick start

```bash
npm install
npm run dev
```

Expects the backend API at `BACKEND_URL` (see `.env.local`, defaults to `http://localhost:8080`).
